Steam Patch Redesign v3

客户端只负责注入，服务端负责补丁库。

这一版把 Steam 补丁重做拆成两个清晰入口：游戏详情页的 Steam 补丁 Tab 只展示已匹配补丁并执行注入；服务端补丁库 Tab 扫描 OpenList / 本地补丁、分析压缩包目录、匹配游戏并生成 Manifest。安卓端不显示入口。

客户端 Tab 注入确认 服务端补丁库 匹配确认 Manifest 手机隐藏态

v3 的边界

不要让玩家在详情页管理补丁规则；不要让服务端决定用户本机 Steam 路径。

注入浏览已匹配补丁、选择目录、备份、写入、回滚。
匹配扫描补丁包、目录树、候选游戏、Manifest。
Dry-run注入前展示新增/覆盖/风险，不再盲写。
隐藏Android 不展示 Steam 补丁入口。
