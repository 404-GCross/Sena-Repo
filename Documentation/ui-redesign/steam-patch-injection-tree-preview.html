实际执行流程

服务端负责判断结构和给 manifest，客户端负责本地 dry-run、备份和解压落地。

Pipeline
1服务端扫描读取压缩包列表，生成虚拟目录树。
2生成规则推荐 strip_components、target_mode 和风险。
3客户端下载下载到补丁缓存，校验 hash / size。
4本地预演结合游戏目录计算最终写入路径。
5备份覆盖覆盖文件先备份，记录批次 manifest。
6注入回滚成功写入；失败按 manifest 回滚。
