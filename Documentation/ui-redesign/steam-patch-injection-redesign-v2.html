补丁首页 目录树配置 注入确认 进度回滚 手机隐藏 接口契约

核心改法：注入前先“看见压缩包”，而不是让用户手填目录猜结果。

服务端扫描补丁压缩包内部结构，生成目录树、推荐剥离层级和风险项。客户端展示原始结构与最终写入预览，用户确认后再下载、备份、注入。这样能解决目录重叠、补丁根目录猜错、覆盖风险不透明的问题。

5. 手机端隐藏态

Steam 补丁注入是桌面本地文件系统能力，Android 不显示入口；如果用户从深链进入，只显示不可用说明，不提供配置表单。

工具

🖥

Steam 补丁功能仅支持桌面端

该功能需要访问本机 Steam 库、读取压缩包并写入游戏目录。请在 Windows 或 Linux 客户端中使用。
